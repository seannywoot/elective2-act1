## 📋 Project Overview

A modern, responsive personal portfolio website showcasing my skills as a Front-End Developer and UI/UX Designer. The site features an elegant design with interactive elements, dark/light theme toggle, and smooth animations.

## ✨ Features

### Core Functionality
- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Dark/Light Theme Toggle** - Switch between themes with animated SVG icons
- **Interactive Elements** - Hover effects, animations, and smooth transitions
- **Random Info Modal** - Click the info button to discover fun facts about me
- **Social Media Integration** - Direct links to GitHub, LinkedIn, and Facebook profiles

### Interactive Elements
- **Profile Image Animation** - Hover to see rotation and scale effects
- **Skill Tags** - Clickable tags with hover animations
- **Bio Text Easter Egg** - Double-click the bio text for a color surprise
- **Smooth Scrolling** - Enhanced navigation experience
- **Button Animations** - Scale effects on click for better user feedback

### Design Features
- **Modern UI** - Clean, professional design with glassmorphism effects
- **Custom Icons** - SVG icons for theme toggle (moon/sun) and info button
- **Color-Adaptive Icons** - Social media icons change color based on theme and hover state
- **Backdrop Blur Effects** - Modern visual depth with blur filters
- **Smooth Transitions** - All interactions have smooth 0.3s transitions

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Advanced styling with:
  - Flexbox layout
  - CSS Grid
  - Custom animations and transitions
  - CSS filters for icon color manipulation
  - Backdrop filters for glassmorphism effects
  - Media queries for responsive design
- **JavaScript (ES6+)** - Interactive functionality:
  - Theme switching logic
  - Modal management
  - Dynamic content generation
  - Event handling
  - DOM manipulation

## 🎨 Design Highlights

### Color Scheme
- **Light Mode:** Warm beige (#DBDABE) with blue accents (#536895, #45577c)
- **Dark Mode:** Dark blue-gray (#2c3e50, #34495e) with light text (#ecf0f1)

### Typography
- **Font Family:** Poppins (Google Fonts)
- **Weights:** 300, 400, 600, 700
- **Responsive sizing** with proper hierarchy

### Layout
- **Container-based design** with max-width constraints
- **Centered layout** with proper spacing
- **Card-based sections** with rounded corners and shadows

## 📱 Responsive Breakpoints

- **Desktop:** 768px and above
- **Mobile:** Below 768px with optimized layout adjustments

## 🚀 Getting Started

1. **Clone or download** the project files
2. **Open `index.html`** in your web browser
3. **Ensure all assets** are in the correct directories:
   - Images in `src/` folder
   - CSS in `style.css`
   - JavaScript in `script.js`
